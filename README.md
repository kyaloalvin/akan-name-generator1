# akan-name-generator1
## Description
A web application that takes a user's datee of birth and gender, calculates the day of the week they were born using a mathematical formula, and displays their corresponding Ghanaian Akan name.
In Akan culture, children are frequently given their first name according to the day of the week they were born and their gender.
